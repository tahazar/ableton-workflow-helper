# Library

Git-versioned musical memory (design: `docs/design/library-kb.md`).

| Path | What |
|---|---|
| `clips/<category>/<slug>.md` | Saved clips: YAML frontmatter + executable bar\|beat notation. `awh save` writes them, `awh lib place` plays them back into any Set |
| `clips/INDEX.md` | Browse/grep entry point, generated by `awh lib index` and on every save |
| `templates/midi-clip.xml` | The golden .alc template captured from Live 12 via `awh lib capture-template` (needed once, before `awh lib export-alc`) |
| `mirror.json` | Live-browser mirror identity: stable PackUniqueID + monotonically bumped PackRevision (the bump makes Live re-index) |

The Live-visible mirror (`../live-mirror/`, gitignored) is generated and
disposable: `awh lib export-alc` rebuilds it from these entries. Edit the
markdown entries and re-export; never edit the mirror by hand.

Capturing the golden template (one-time, in Live 12): put one MIDI clip with
at least one note on a track with no devices, drag the clip into your User
Library, then run `awh lib capture-template <path-to-that>.alc`. The track
must have **no devices** because a Live Clip carries its source track's
device chain, which would ride along into every exported clip.
