# Library

Git-versioned musical memory (design: `docs/design/library-kb.md`).

| Path | What |
|---|---|
| `clips/<category>/<slug>.md` | Saved clips: YAML frontmatter + EXECUTABLE bar\|beat notation. `awh save` writes them, `awh lib place` plays them back into any Set |
| `clips/INDEX.md` | Generated by `awh lib index` (and on every save) — browse/grep entry point |
| `templates/midi-clip.xml` | The golden .alc template captured from Live 12 via `awh lib capture-template` (needed once, before `awh lib export-alc`) |
| `mirror.json` | Live-browser mirror identity: stable PackUniqueID + monotonically bumped PackRevision (the bump is what makes Live re-index) |

The Live-visible mirror itself (`../live-mirror/`, gitignored) is generated and
disposable: `awh lib export-alc` rebuilds it from these entries. Never edit the
mirror by hand — edit the markdown entries and re-export.

Capturing the golden template (one-time, in Live 12): put ONE MIDI clip with at
least one note on a track with **no devices**, drag the clip into your User
Library, then run `awh lib capture-template <path-to-that>.alc`. The no-devices
part matters — a Live Clip carries its source track's device chain, and the
template's chain would ride along into every exported clip.
